# نظام حجوزات صالون الحلاقة

موقع حجز للزباين مع لوحة تحكم لصاحب الصالون. عربي من اليمين، ومصمم للموبايل أولاً، وبتوقيت بغداد.

**التقنيات:** Next.js 15 (App Router) و TypeScript و Tailwind CSS 4 و Supabase (قاعدة البيانات وتسجيل الدخول) و Lucide.

---

## شنو يسوي

**للزبون**
- صفحة رئيسية فيها اسم الصالون وشعاره، الخدمات والأسعار، الحلاقين، أوقات الدوام، الموقع، وزر واتساب ثابت.
- حجز بأربع خطوات: الخدمة، ثم الحلاق (أو "أي حلاق فارغ")، ثم اليوم والوقت، ثم الاسم والرقم.
- الأوقات تنحسب مباشرة من قاعدة البيانات: الدوام، الاستراحة، العطل، الحجوزات الموجودة، ومدة الخدمة.
- الأوقات متسلسلة حسب مدة الخدمة (10:00، 10:30، 11:00...) وبعد كل حجز يبدي الموعد اللي بعده مباشرة بدون فراغات. تكدر تطفيها من الإعدادات وترجع لفرق ثابت.
- الوقت المحجوز يطلع مضلل ومكتوب عليه "محجوز" وما ينختار.
- صفحة نجاح فيها رمز الحجز، وزر يرسل تفاصيل الحجز للصالون على الواتساب.
- صفحة "حجوزاتي": يشوف حالة حجزه برمز الحجز ورقم الموبايل، ويكدر يلغيه قبل الموعد بساعة.

**لصاحب الصالون** (`/admin`)
- دخول آمن بالإيميل وكلمة السر (Supabase Auth).
- الرئيسية: حجوزات اليوم، الحجوزات اللي تنتظر تأكيد، عدد حجوزات الشهر، والمتوقع اليوم.
- تقويم بثلاث طرق عرض: يوم (عمود لكل حلاق)، أسبوع، وشهر.
- إدارة الحجوزات: إضافة، تعديل، تأكيد، إكمال، "ما حضر"، وإلغاء. وبيها رسائل تأكيد وتذكير جاهزة على الواتساب.
- بحث بالاسم أو الرقم، وفلترة حسب الحالة، وتقسيم القادمة والسابقة.
- الزباين: سجل كل زبون، عدد زياراته وغياباته، مجموع دفعه، وملاحظاته (الملاحظات تظهر بكل حجز له).
- الخدمات (الاسم، السعر، المدة، الإخفاء) والحلاقين.
- دوام كل يوم مع الاستراحة، والعطل والأوقات المسكّرة للصالون كله أو لحلاق واحد.
- تقارير: الإيراد المحصّل والمتوقع، الإلغاء والغياب، الزباين الجدد، إيراد يومي، وتوزيع حسب الخدمة والحلاق.
- إعدادات: معلومات الصالون والتواصل وقواعد الحجز (الفرق بين المواعيد، أقصى مدة للحجز المسبق، تأكيد تلقائي...).

## الحماية ومنطق الحجز

- **منع التداخل بقاعدة البيانات نفسها:** قيد `EXCLUDE` على `(barber_id, وقت الموعد)`. حتى لو 20 زبون ضغطوا بنفس الثانية، واحد بس ينجح (مختبر).
- **كل طرق الكتابة تنفحص:** Trigger يرفض أي حجز خارج الدوام، أو بالاستراحة، أو بوقت مسكّر، سواء جا من الموقع أو من لوحة التحكم.
- **منع التكرار:** نفس الزبون ما يكدر يحجز موعدين متداخلين، وعنده حد أقصى للحجوزات القادمة.
- **RLS مفعل على كل الجداول:** الزائر يشوف بس معلومات الصالون والخدمات والحلاقين الفعالين. الحجوزات والزباين ما تنقرأ إلا للمدير. الزبون يوصل لحجزه بس عن طريق دوال محددة تحتاج الرمز والرقم سوية.
- **التحقق بالسيرفر:** كل طلب يمر على Zod بالسيرفر، وبعدين على فحوصات Postgres.
- **ما يحتاج service_role أبداً.** التطبيق يستخدم anon key فقط، والصلاحيات كلها من RLS.
- أرقام الموبايل العراقية تتوحد تلقائياً (`0770…`، `+964…`، أو أرقام عربية `٠٧٧٠…`).

## الإعداد خطوة بخطوة

### 1) سوّي مشروع Supabase

1. ادخل [supabase.com](https://supabase.com) وسوّي مشروع جديد. اختار منطقة قريبة (مثلاً Frankfurt).
2. من **SQL Editor**، افتح ملف `supabase/migrations/20261104000000_init.sql`، انسخ كل محتواه، والصقه وشغله.
   (أو إذا عندك Supabase CLI: `supabase link` ثم `supabase db push`.)
3. من **Authentication > Users > Add user**، سوّي حساب صاحب الصالون (إيميل وكلمة سر قوية)، وفعّل "Auto Confirm User".
4. من **Authentication > Sign In / Providers**، طفي "Allow new users to sign up" حته محد غيرك يسوي حساب.
5. ارجع لـ **SQL Editor** وشغل هذا الأمر مرة وحدة (غيّر القيم):

   ```sql
   select public.setup_shop('firas-salon', 'صالون فراس', 'owner@email.com');
   ```

   هذا يسوي الصالون، ويحط دوام افتراضي (كل يوم 4 العصر لـ 12 بالليل والجمعة عطلة)، ويخلي الحساب مدير للصالون.
   الـ slug (أول قيمة) لازم يكون حروف إنكليزية صغيرة وأرقام وشرطة فقط.

### 2) شغله على جهازك

```bash
npm install
cp .env.example .env.local
```

عبّي `.env.local` من **Project Settings > API** بـ Supabase:

```
NEXT_PUBLIC_SUPABASE_URL=https://xxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJ...
NEXT_PUBLIC_SHOP_SLUG=firas-salon
```

```bash
npm run dev
```

افتح `http://localhost:3000/admin`، سجل دخول، وبعدين:
1. **الإعدادات:** اسم الصالون، الواتساب، العنوان، رابط الخريطة، الشعار.
2. **الخدمات:** أضف الخدمات بأسعارها ومددها.
3. **الحلاقين:** أضف حلاق واحد على الأقل.
4. **الدوام والعطل:** عدل الأوقات والاستراحة.

بعدها صفحة الزبون `http://localhost:3000` جاهزة للحجز.

### 3) ارفعه على Vercel

1. ارفع المشروع على GitHub.
2. ادخل [vercel.com](https://vercel.com) > **Add New > Project**، واختار المستودع.
3. بـ **Environment Variables** أضف نفس المتغيرات الثلاث.
4. اضغط **Deploy**.
5. بـ Supabase، من **Authentication > URL Configuration**، حط رابط الموقع (مثلاً `https://firas-salon.vercel.app`) بـ Site URL.
6. إذا عندك دومين، أضفه من **Vercel > Settings > Domains**.

## تشغيل الاختبارات

اختبارات قاعدة البيانات تشتغل على أي Postgres 15+:

```bash
PGHOST=localhost PGUSER=postgres ./supabase/tests/run.sh
```

تفحص: الأوقات المتاحة، منع التداخل، التكرار، خارج الدوام، الاستراحة، العطل، رقم غلط، RLS للزائر وللمستخدم الغريب وللمدير، الإلغاء، و20 حجز بنفس اللحظة على نفس الوقت (لازم واحد بس ينجح).

## ملاحظات

- **الواتساب:** الرسائل حالياً تنفتح جاهزة بضغطة وحدة (روابط `wa.me`)، وما تحتاج اشتراك. إذا تريد إرسال تلقائي بدون ضغط، يحتاج WhatsApp Business API (مدفوع ويحتاج توثيق حساب).
- **الصور:** الشعار وصور الحلاقين تنضاف كروابط. تكدر ترفعها على Supabase Storage أو أي مكان، وتلصق الرابط.
- **الخط:** الموقع يستخدم Readex Pro (مجاني ومفتوح). خط ثمانية رخصته المجانية للاستخدام الشخصي بس وما تسمح تحطه بموقع. إذا الصالون اشترى رخصة ويب من ثمانية، حط رابط ملف الـ CSS مالته بـ `NEXT_PUBLIC_THMANYAH_CSS` والموقع يتحول عليه تلقائياً.
- **`scripts/local-api`:** أداة اختبار محلية فقط تحاكي واجهة Supabase فوق Postgres عادي، حته نجرب الموقع كامل بدون Docker. ما تنرفع ولا تستخدم بالإنتاج.

## وصل الحجز (صورة)

- **نسخة الزبون:** بعد الحجز تطلع صورة الوصل بصفحة التأكيد، وبيها زر "دز الوصل" و"احفظ الوصل". الصورة من `/api/booking-receipt?code=…&phone=…`.
- **نسخة الحلاق:** كل حجز أونلاين يوصل للحلاق اللي انحجز عنده كصورة وصل على التيليغرام (تلقائي، من قاعدة البيانات عن طريق pg_net). الصورة من `/api/receipt/<token>` والرمز سري لكل حجز.
- التفعيل مرة وحدة: طبّق `supabase/migrations/20261105010000_barber_receipts.sql`، سوّ بوت من @BotFather، حط التوكن واسم البوت بـ `private.notify_config` (الأمر مكتوب بأول الملف)، وشغّل `select private.telegram_set_webhook('firas-salon');`.
- بعدها من **لوحة التحكم ← الحلاقين** كل حلاق عنده رابط. يفتحه من موبايله ويدوس Start، ومن هاي اللحظة توصله حجوزاته.
- الصورة تنرسم بالسيرفر بـ `@napi-rs/canvas` (يدعم الحروف العربية المتصلة) والخطوط موجودة بـ `src/assets/fonts`.
